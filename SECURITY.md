# Security reports / Tietoturvailmoitukset

Do not open a public issue for a security vulnerability. Use the private contact form on the [Louhos website](https://rasse2009.fi/louhos/#tilityypit). State the affected tool, impact and minimal reproduction steps. Never include passwords, live session tokens or customer files. Further details can be arranged privately.

Älä julkaise haavoittuvuutta julkisena issuena. Käytä [Louhoksen yhteydenottolomaketta](https://rasse2009.fi/louhos/#tilityypit). Kerro työkalu, vaikutus ja lyhyet toistovaiheet. Älä liitä salasanoja, toimivia istuntotunnisteita tai asiakkaiden tiedostoja. Lisätiedot sovitaan yksityisesti.

This repository contains public documentation only. Application security reports use the same private channel.
