# Louhos

Louhos on yksityisesti ylläpidetty tuotantotyökalujen kokonaisuus. Se on käytössä osoitteessa [rasse2009.fi/louhos](https://rasse2009.fi/louhos/).

Tämä repository ei ole asennettava sovellus eikä sisällä tuotantolähdekoodia. Sen tarkoitus on pitää julkisesti nähtävissä, mitä Louhos sisältää tällä hetkellä.

## Toteutetut työkalut

| Työkalu | Mitä se tekee | Sivusto |
| --- | --- | --- |
| **Cue** | Rakentaa ja ajaa cue-listoja. Cue-toiminnot voivat lähettää MIDI-, OSC- ja HTTP-signaaleja. Käyttöliittymässä on erilliset Run- ja Edit-tilat. | [Avaa Cue](https://rasse2009.fi/louhos/cue/) |
| **Interval** | Näyttää vMixin Program- ja Preview-inputit sekä seuraa kameranvaihtojen kestoa. Inputteja voidaan nimetä, järjestää, rajata välilehdille ja ottaa mukaan/pois laskennasta. | [Avaa Interval](https://rasse2009.fi/louhos/interval/) |
| **File Transfer** | Hallitsee projekteja, kansioita, tiedostoja ja jakolinkkejä. Linkille voi määrittää voimassaolon, salasanan, latausten, esikatselun ja kommentoinnin. | [Avaa File Transfer](https://rasse2009.fi/louhos/FileTransfer/) |
| **Equipment** | Kokoaa tuotantokaluston, varaukset ja saatavuuden samaan näkymään. | [Avaa Equipment](https://rasse2009.fi/louhos/equipment/) |
| **Plan** | Teknisessä suunnittelussa käytettävä näkymä tilojen, laitteiden ja yhteyksien hahmottamiseen. | [Avaa Plan](https://rasse2009.fi/louhos/plan/) |
| **Stage** | Hallitsee ohjelmaa, lavakelloa ja tuotannon ajoitusta. | [Avaa Stage](https://rasse2009.fi/louhos/stage/) |
| **Rundown** | Auttaa lähetyksen käsikirjoituksen ja ohjelman kulun suunnittelussa. | [Avaa Rundown](https://rasse2009.fi/louhos/rundown/) |
| **Show** | Kokoaa live-esityksen tärkeät tiedot ja ohjauksen tuotannon yhteiseen näkymään. | [Avaa Show](https://rasse2009.fi/louhos/show/) |
| **Vision** | Tuotannon vedosten ja visuaalisen materiaalin tarkastelu. | [Avaa Vision](https://rasse2009.fi/louhos/vision/) |
| **Comms** | Tuotannon puheyhteys kanaville ja tiimille. | [Avaa Comms](https://rasse2009.fi/louhos/comms/) |

## Julkinen repository

Louhos on tällä hetkellä suljettu projekti. Täällä ei julkaista:

- tuotantoympäristön asetuksia, palvelin- tai vMix-osoitteita
- käyttäjiä, projekteja, tiedostoja tai jakolinkkejä
- API-avaimia, tunnuksia tai muuta käyttöoikeuksiin liittyvää tietoa
- palvelin- ja hallintapaneelikoodia

Jos Louhoksesta julkaistaan myöhemmin ladattava komponentti, dokumentaatio tai avoin integraatio, se lisätään tähän repositoryyn erillisenä ja käyttöohjeineen.
