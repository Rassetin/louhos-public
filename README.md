# Louhos Public

Julkinen, staattinen esittelysivu Louhokselle. Tämä kansio ei sisällä sovellusten lähdekoodia, API-osoitteita, käyttäjätietoja tai tuotantoasetuksia.

## Julkaisu GitHub Pagesiin

1. Luo GitHubiin uusi **public** repository nimellä `louhos-public`.
2. Kopioi tämän kansion sisältö uuden repositorion juureen.
3. Repositorion **Settings → Pages**: valitse julkaisuhaara `main` ja kansio `/ (root)`.

Sivusto julkaistaan osoitteeseen `https://rassetin.github.io/louhos-public/`.
