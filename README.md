# Louhos

> Työkalut live- ja tuotantotiimeille.

Louhos on kokoelma selkeitä ajopintoja tuotantotilanteisiin. Sen lähtökohta on yksinkertainen: tärkein tieto ja toiminto ovat näkyvissä silloin, kun niitä tarvitaan — ilman tarpeetonta hälyä.

## Työkalut

| Työkalu | Käyttö |
| --- | --- |
| **Cue** | Cue-listojen rakentaminen ja ajo live-tuotantoihin. |
| **Interval** | Kameranvaihtojen seuranta ja ajastus vMixin Program- ja Preview-inputeille. |
| **File Transfer** | Projektien, kansioiden ja jakolinkkien hallinta sekä tiedostokommentit. |

## Suunnitteluperiaatteet

- **Tilannetieto ensin** — olennainen tieto on lähellä toimintoa.
- **Yhteinen käyttöliittymä** — samat rakenteet ja hallintatavat eri työkaluissa.
- **Skaalautuva käyttö** — näkymä toimii eri kokoisilla näytöillä ilman että työnkulku hajoaa.
- **Yksityinen tuotantodata** — julkinen esittely ja käyttödata ovat erillään.

## Projektin tila

Louhos on aktiivisessa kehityksessä. Tämä public-repository esittelee projektin yleisesti; tuotantokäyttöön tarkoitetut sovellukset, asetukset ja integraatiot pidetään yksityisinä.

Julkinen repository ei sisällä:

- tuotantoympäristön asetuksia tai palvelinosoitteita
- käyttäjä-, projekti- tai tiedostosisältöjä
- API-avaimia, tunnuksia tai muita salaisuuksia
- hallintapaneelin tai sisäisten työkalujen lähdekoodia

## Palaute ja tietoturva

Havaituista ongelmista tai kehitysideoista voi avata [Issue](../../issues). Älä julkaise issueissa tunnuksia, jakolinkkejä, tuotantoprojektien nimiä tai muuta arkaluonteista materiaalia. Tietoturvaan liittyvistä havainnoista kannattaa olla yhteydessä yksityisesti repositoryn omistajaan.
